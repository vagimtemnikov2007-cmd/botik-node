# Botik Node

Telegram-бот на Node.js 22+ с интерфейсом на русском. Самостоятельная реализация, вдохновлённая [vladimirsnow/botik](https://github.com/vladimirsnow/botik).

## Возможности

| Источник | Что отправляет бот |
| --- | --- |
| YouTube / Shorts | Видео, MP3 по команде `/audio` |
| X / Twitter | Видео, фото, смешанные альбомы, текст публикации через FxTwitter; резервная загрузка видео через yt-dlp |
| Instagram | Reels и видеопосты через yt-dlp; фото-карусели не реализованы |
| Pinterest / pin.it | Видео через yt-dlp, фото через OpenGraph страницы пина |
| TikTok | Видео через yt-dlp; фото-слайдшоу отдельно не реализованы |
| Музыка | `/music исполнитель название` — первый результат поиска YouTube в MP3 с метаданными |

Улучшения: ограниченная очередь, отмена ожидающих и активных загрузок, выбор 360/720/1080p, сжатие крупных видео, кеш Telegram file_id, несколько ссылок в одном сообщении, обработка скрытых ссылок и подписей, ограничение частоты запросов, allowlist пользователей, очистка временных файлов, healthcheck, graceful shutdown, polling и защищённый webhook.

## Быстрый запуск через Docker

1. Создайте бота в [@BotFather](https://t.me/BotFather), получите токен.
2. В папке проекта выполните:

```bash
cp .env.example .env
# Укажите BOT_TOKEN в .env
docker compose up -d --build
docker compose logs -f bot
```

Docker устанавливает Node.js, yt-dlp, FFmpeg и FFprobe. По умолчанию работает long polling: публичный домен не нужен. Токен храните только в `.env`.

## Запуск без Docker

Понадобятся Node.js 22.9+ (рекомендуется 24 LTS), FFmpeg/FFprobe и актуальный [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation). Сам бот написан на JavaScript; yt-dlp — внешний инструмент скачивания.

```bash
# Linux, если yt-dlp ещё не установлен:
python3 -m venv .venv
.venv/bin/pip install -U 'yt-dlp[default]'
# В .env задайте YTDLP_PATH=/абсолютный/путь/.venv/bin/yt-dlp
# FFmpeg установите пакетным менеджером вашей ОС.

npm ci
cp .env.example .env
# Укажите токен и при необходимости YTDLP_PATH
npm run doctor
npm start
```

`npm run doctor` проверяет программы и конфигурацию без отправки сообщений в Telegram. `npm test` запускает автоматические тесты без токена и внешних сервисов.

`npm run smoke -- https://ссылка_на_публикацию` проверяет настоящее скачивание без подключения Telegram, выводит типы и размеры файлов и удаляет временные файлы. Для этой проверки BOT_TOKEN не нужен; yt-dlp и FFmpeg должны быть установлены. Можно передать несколько ссылок.

## Команды и использование

Просто отправьте ссылку. Бот ответит медиа на исходное сообщение. Для музыки используйте `/music Daft Punk Get Lucky`, для аудио `/audio https://youtu.be/...`. В группе также работает `@имя_бота исполнитель название`.

- `/quality` — выбрать максимальную высоту видео кнопками.
- `/cancel` — отменить ваши задачи в текущем чате; уже отправленные файлы остаются.
- `/status` — количество активных/ожидающих задач и ваше качество.
- `/id` — узнать свой ID для настройки `ALLOWED_USERS`.
- `/help` — справка.

Для автоматической обработки обычных сообщений в группе отключите Privacy Mode через BotFather (`/setprivacy`) и повторно добавьте бота. Для канала добавьте бота с правом отправки сообщений. Когда задан `ALLOWED_USERS`, сообщения каналов без пользовательского отправителя не обрабатываются.

## Настройки

Все параметры перечислены в [.env.example](.env.example). По умолчанию: 2 параллельные задачи, 30 задач всего, до 3 ссылок и 10 файлов за запрос, 10 секунд между запросами одного пользователя в чате, видео до 30 минут, таймаут загрузки 5 минут, файлы до 49 МиБ. Качество — верхняя граница: доступный на сайте формат может быть ниже.

Крупные видео бот пытается сжать через FFmpeg. Если результат не помещается, предлагает аудио или более короткое видео. Картинки свыше 9 МиБ отправляются документом. Очень большие исходники не скачиваются целиком. FFmpeg требует CPU: на небольшом сервере выставьте `CONCURRENCY=1`.

Очередь, настройки качества и кеш находятся в памяти одного процесса. Перезапуск сбрасывает их и прерывает незавершённые задачи. Кеш живёт до 6 часов, содержит file_id, а не файлы. Частично отправленный запрос не повторяется автоматически, чтобы не дублировать альбомы. Это версия для одного экземпляра; для нескольких серверов потребуется общая очередь и хранилище.

## Cookies и доступность платформ

Некоторые публикации требуют авторизации, а YouTube/Instagram могут ограничивать серверные IP. Для доступа к своим доступным публикациям экспортируйте Netscape `cookies.txt` и задайте `COOKIES_FILE`. Не добавляйте этот файл в Git. При cookies личного аккаунта ограничьте доступ к боту через `ALLOWED_USERS`.

В Docker смонтируйте файл только для чтения и задайте путь внутри контейнера:

```yaml
# Добавьте в services.bot в compose.yaml:
volumes:
  - ./cookies.txt:/run/secrets/cookies.txt:ro
environment:
  COOKIES_FILE: /run/secrets/cookies.txt
```

Внешние сервисы и разметка сайтов меняются: наличие адаптера не гарантирует загрузку каждой ссылки. FxTwitter используется для публичных постов X; если сервис недоступен, резервный путь yt-dlp поддерживает видео, но не текстовые посты и фото. Pinterest использует OpenGraph для фото, поэтому размер изображения зависит от страницы. Фото-карусели Instagram и TikTok, Stories, прямые трансляции и закрытые публикации без доступа не поддерживаются. Cobalt и другие публичные шлюзы здесь не используются.

Обновляйте yt-dlp при изменениях сайтов: `.venv/bin/pip install -U 'yt-dlp[default]'` или пересоберите Docker с `docker compose build --no-cache` и запустите `docker compose up -d`.

## Webhook и хостинг

На VPS или Koyeb можно запускать Dockerfile. Для polling используйте один Worker и переменную `BOT_TOKEN`. Для Web Service задайте порт 8000, проверку `/healthz`, `WEBHOOK_URL=https://ваш-домен` и случайный `WEBHOOK_SECRET` длиной 16–256 символов (`A-Z`, `a-z`, `0-9`, `_`, `-`). Путь `/telegram` бот добавляет автоматически. HTTPS обеспечивает хостинг или reverse proxy.

```bash
openssl rand -hex 32
```

Сервер проверяет секрет Telegram, ограничивает размер запроса и подтверждает update после принятия задачи. Очередь не сохраняется на диск: для гарантированной доставки через перезапуски нужно добавить постоянное хранилище. `/healthz` сообщает готовность подключения к Telegram, без секретов.

## Проверка реальных загрузок

Автотесты проверяют парсинг, очередь, отмену процессов, ограничения сети и поведение бота с подменённым Telegram API. После запуска с вашим токеном отправьте по одной публичной ссылке каждого типа: YouTube, Shorts, X с фото и видео, Reel, Pinterest-фото и Pinterest-видео, pin.it. Проверьте `/audio`, `/quality`, отмену длинной загрузки и группу. Живые загрузки зависят от сети, авторизации и состояния платформ.

Основные технические источники: [grammY](https://grammy.dev/guide/deployment-types), [Telegram Bot API](https://core.telegram.org/bots/api), [yt-dlp](https://github.com/yt-dlp/yt-dlp), [FxEmbed](https://docs.fxembed.com/).
